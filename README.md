# Task-Mesh — Native Android App (Kotlin & Jetpack Compose)

"A little learning. Every day."

Task-Mesh is an offline-first daily English vocabulary learning application for Android with Devanagari Hindi translations.

## Specifications
- **30 Days of Content**: Exactly 7 words per day (210 unique vocabulary entries).
- **Themes**: System, Light, and Dark modes.
- **Local Persistence**: SharedPreferences for instant, offline progress saving.
- **Architecture**: 100% Jetpack Compose single-activity architecture with Material 3.

## How to Build in Android Studio
1. Open Android Studio.
2. Select **File > Open...** and select the `TaskMesh-Android` folder.
3. Allow Gradle to sync dependencies.
4. Click **Run > Run 'app'** or connect an Android device / emulator.
5. To generate an APK: **Build > Build Bundle(s) / APK(s) > Build APK(s)**.
